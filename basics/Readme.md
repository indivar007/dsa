Start with arrays & strings (this is 70% of interview DSA anyway)

Find the largest/smallest element in an array
Reverse an array (in-place, two-pointer)
Check if a string is a palindrome
Find the second largest element in an array
Move all zeros to the end (in-place)
Find the missing number in an array of 1 to N
Find duplicate(s) in an array
Two Sum (array, target sum) — this one's important, classic hashmap pattern
Reverse a string / reverse words in a string
Check if two strings are anagrams

Then basic sorting/searching (do these by hand first, not just call a library function)

Implement binary search
Implement bubble sort and selection sort (just to understand the mechanics — you won't use these in real interviews but they build intuition)
Find the first and last occurrence of a target in a sorted array (binary search variant)

Then basic hashmap/set patterns

Find the frequency of each element in an array
Find the first non-repeating character in a string
Group anagrams together

Then basic recursion (don't skip this — it's the bridge to trees/backtracking later)

Factorial of a number
Fibonacci (recursive, then optimize with memoization)
Sum of digits of a number (recursive)
Print all subsets of a string/array (basic recursion → leads into backtracking)
